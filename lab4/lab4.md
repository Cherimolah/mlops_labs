**По результатам лабораторной работы базово освоить утилиту dvc.**

К сожалению с google drive поработать не получилось ни через авторизацию в браузере (пишет, что подозрительное приложение),
ни через авторизацию по ключу через сервисный аккаунт, так как упираемся в лимиты доступа (нельзя редактировать без подписки).
Поэтому решили как аналог настроить локальный remote.

Создано три версии датасета Titanic:
базовая выборка трёх признаков, версия с заполненными пропусками в Age и версия с one-hot-encoding признака Sex.
Каждая версия зафиксирована отдельным коммитом и тегом в Git и отправлена в локальную папку командой dvc push.

Освоили переключение между версиями с помощью git checkout + dvc checkout

Также был протестирован dvc пайплайн, шаги находятся в dvc.yaml и командой dvc repro можно по порядку пройти по шагам обработки данных.
